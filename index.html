BF OSD Text Editor

Inspect cloud-built Betaflight firmware locally. Experimental — bench-test HEX export for DISARMED only.

1. Load firmware

Select an Intel HEX file.

2. OSD preview

DISARMED

Illustrative preview only. Betaflight 4.5.5 MSP DisplayPort sends up to 30 characters; analogue OSD clips at the end of its 30-column row. Actual rendering varies.

3. Detected text

Exact NUL-terminated ASCII candidates. Duplicate matches are shown separately. All plain-text candidates can be edited for preview and analysis, including duplicate matches. Plain-text preview limit: 30 ASCII characters (4.5.5 MSP ceiling, not a verified patch limit). Original length is the conservative in-place storage budget, not proof of patch safety. Longer text requires verified extra storage or relocation. Format strings remain locked. No edits are applied to firmware.

4. Firmware export

Initial test: change exactly one DISARMED candidate to eight printable ASCII characters. Other edits and longer strings block export. Candidate identity is not verified.

Extended storage analysis reports raw pointer candidates only; relocation remains blocked until references and flash layout are verified. Project repository
